# 供应商错误处理

| 情况 | 处理 |
| --- | --- |
| 无工具或缺少身份工具 | 检查所选领域入口和 Key 身份能力；重连刷新；不能认为业务查询已完成 |
| `INSTALLED_AUTHORIZATION_REQUIRED` | 初始化与工具发现已完成，缺少对应 `supplier.fabric.identity.read` 或 `supplier.garment.identity.read`；联系管理员授权 |
| `VERIFIED` | 已实际调用并校验该领域身份工具；不代表订单等业务已开放 |
| 401 / 账号或绑定失效 | 请管理员核对 Key、Client、供应商主账号状态及已有认证版本；不切到 ERP 入口 |
| 403 / 能力不足 | 核对 Key 白名单和账号当前权限；Skill 不自行扩大权限 |
| 429 | 按服务端重试提示稍后重试，避免连续重复请求 |
| 超时 / 目录不可用 / 5xx | 如实报告未验证，不使用缓存身份伪装成功，不输出内部响应体 |
| 错域或身份字段不完整 | 停止验证，核对领域与 MCP 地址，不报告 VERIFIED |

排查时可分享脱敏状态、请求时间和管理员可查询的请求 ID；不分享 Authorization 或个人 Key。
