# 供应商工作流

## 确认接入身份

确定用户要使用面料还是成衣连接。检查该连接的工具列表，调用对应身份工具且传入空参数。展示返回的领域、主账号、租户、公司编码和 Client 编码；面料展示返回的区域，成衣不补造区域。字段不包含供应商名称时不要凭公司编码猜测名称。

## 使用业务能力

首版只有身份查询。用户查询订单、报价或发货而当前连接没有相应工具时，说明当前未开放或未获授权，请管理员核对；身份查询结果不等于业务授权。未来有真实业务工具时先查询再选定，写入遵循该工具的契约和当前用户授权。

## 刷新授权

Key 由管理员在对应 Client 下签发和授权。修改授权后重连 MCP 或新建会话，重新检查工具列表。Skill 不签发 Key，也不修改门户账号、权限或租户。
