# 身份与凭证

API Key 绑定一个领域、租户、供应商和正式主账号。面料、成衣、ERP 的凭证互不替代；不要使用身份参数、伪造请求头或直接调用后端内部目录绕过绑定。账号、供应商或认证版本失效时按服务端拒绝结果处理。

个人 Key 只通过本地安全输入进入用户级私有 MCP 配置。安装不意味着可以把凭证粘贴到聊天、源码、业务报表、共享配置或 Connector 包。结果中也不输出 SQL、上游机器 Token 或内部堆栈。

面料库存写入按[库存工作流](fabric-inventory.md)预检、确认并调用独立提交工具；无预览 ID，每次确认的新提交使用新幂等键，同一次网络重试必须沿用原键及原内容。超时不自动重试，查询当前库存后请用户决定。其他写工具按实际契约与风险说明目标和影响；付款、审批、发货、删除等高影响操作在需要时取得明确确认。普通读取沿用用户现有授权直接执行。
